# Student Management System

A Python-based student management system developed for Software Quality Engineering course.

## Features
1. Add Student (with roll number, name, and marks)
2. View All Students
3. Search Student by Roll Number
4. Update Student Marks
5. Delete Student
6. Generate Grade Report

## Requirements

- Python 3.x
